MGA — My Gym Application
AI Inference, Biometrics & Microservices

Full-stack gym management platform powered by 11 Spring Boot microservices, Flutter Android clients, Kafka event streaming, and dedicated AI engines for real-time posture correction, conversational assistance, and biometric facial authentication.

11 Microservices (Spring Boot) Local K8s + Railway Cloud Apache Kafka (Aiven) PostgreSQL + MongoDB Atlas Cloudflare & K8s Gateway

Core Challenge

Eliminates manual attendance, fragmented scheduling, and lack of real-time member feedback with automated facial check-ins, unified operations, and AI workout insights.

Architectural Highlights

Secured ingress via Cloudflare and K8s Gateway with firewalled internal CRUD services. Features hybrid orchestration across a local Kubernetes cluster and Railway Cloud.

Core AI Engines

Dedicated machine learning pipelines and real-time inference services.
